# Deep Current Studio Website Project

This project is to create a website for the client Deep Current Studio. They are a group in game development and want to get themselves to the public. Currently they have developed one game called Disaster Response Force that will feature in this project.

## Meet the Team
- Zane Marcoe
- Anthony Brunner

## What the Client is looking for
- Multi-page site with static navigation to all pages
- A blog/discussion post that allows admins to post updates and info
- About me page that describes the group and what they want to accomplish along with social links
- Page that describes their current game "Disaster Response Force"
- Custom backgrounds and customizations

## Possibilities
- Allowing users to reply to discussion posts
- Having a login profile page
- Having a single page for all games with links to seperate descriptive pages
